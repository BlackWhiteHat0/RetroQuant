# lab — 實驗測試專區

這裡放「先試試看能不能用」的可行性測試與比較實驗，當作過程紀錄。
**不屬於正式實作**：`src/` 不可以 import 這裡的任何東西；確定可行的做法要重寫進正式模組並經過 PR 審查。

## 規則

- 每次實驗一個資料夾：`lab/YYYY-MM-DD_<簡短主題>/`
- 每個實驗資料夾都要有 `README.md`：目的、環境、怎麼跑、結果、結論與待決定事項
- 下載的原始資料放在該實驗的 `images/`（不進 git，用腳本重新下載）；產出的結果圖放 `outputs/`
- 實驗專用的額外套件寫在該實驗的 `requirements.txt`

## 2026-10-14 補充：報告中未提到、待討論的事項

1. **DexiNed 線條偏粗**（2～4 px），影像四周常出現假的邊框線（kodim01、kodim04），銳利化時會一起被強化，做步驟 ③ 前要先處理。
2. **「主體」的定義**：kodim07 的花叢被判成盆栽、窗戶不算主體；kodim04 主體佔 86%，等於全圖銳利化。
3. **主體本來就很小的情況**：kodim12 的人只佔 7%，偵測正確但銳利化範圍很小，和「誤判碎片」是不同的問題，要不要分開處理？
4. **環境與規格不一致**：這次用 Python 3.12（SPEC 寫 3.11）；`kornia` 只在實驗的 requirements 裡，正式採用 DexiNed 時要補進 `Requirement/` 與 `TECH_STACK.md`。
5. **和 SPEC 的設計對齊**：「先銳利化原圖」和原本「只用權重引導色彩量化、不改原圖」不同，評估方式也會受影響，正式採用時要記到 `DECISIONS.md`。
