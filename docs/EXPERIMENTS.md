| 問題 | 實驗 | 主要指標 |

## 2. 資料集與切分

| 集合 | 內容 | 張數（初估） | 用途 |
|---|---|---|---|
| **驗證集** | 部分 Kodak + 部分合成影像 | 約 8 張 Kodak + 20 張合成 | 只用來選 α/β、γ |
| **測試集** | 其餘 Kodak + 其餘合成 + 精選 SIPI（+ 有標準答案的公開資料，見 §3） | 約 16 張 Kodak + 40 張合成 + N 張 | 參數鎖定後只跑**一次** |

規則
- 切分寫在 `datasets/splits.json`，第 2 週決定後**不再變動**。
- 測試集**不准**拿來調參數。
- 影像分成兩個子群（報告時分開呈現）：`has_voc_object = true/false`（由標準答案或人工判定，不能用模型輸出判定）。

### 2.1 合成影像規格（負責人 B）

| 類型 | 說明 | ROI 標準答案 |
|---|---|---|
| 漸層 + 物件 | 大面積平滑漸層背景 + 小的彩色物件（模擬「背景搶色票」） | 物件遮罩 |
| 幾何形狀 | 多個不同顏色、大小的形狀 | 指定某些形狀為 ROI |
| 紋理 | 高頻紋理背景 + 平滑主體 | 主體遮罩 |
| 高邊緣 | 細線、文字、網格 | 線條遮罩 |

- 每張都用亂數種子產生，可以重現；尺寸 512×512 或 768×512。
- **注意：** 合成影像通常沒有 VOC 物件，S 會幾乎全 0，所以主要拿來驗證邊緣分支和 VQ 的行為。如果要測語意分支，可以把真實人物或動物的去背圖貼到合成背景上（來源必須授權乾淨）。

## 3. ROI 標準答案

> **不可以用模型自己的 S 當 ROI**（循環評估）。

候選方案（由 `DISCUSSION.md` 第 4 題決定）：

| 方案 | 優點 | 缺點 |
|---|---|---|
| (a) 人工標註 Kodak 24 張的主體 | 直接對應主要測試集 | 花時間；「主體」的定義主觀，需要寫標註準則 |
| (b) PASCAL VOC 2012 驗證集的分割標準答案 | 客觀、現成、類別和模型一致 | 影像較小、已被 JPEG 壓縮過；類別和模型相同，會偏向對我們有利（報告要說明） |
| (c) 顯著性資料集（ECSSD / DUTS）的標準答案 | 不分類別的「主體」定義 | 需要確認授權 |
| (d) 合成影像的標準答案 | 完美、免費 | 不是自然影像 |

建議組合：**(d) + (a)** 或 **(d) + (b)**，至少要有一個自然影像來源。

標註準則（若採用 (a)）：
1. ROI = 觀看者第一眼會注意的主體（人、動物、主要物件）；純風景可以標「無 ROI」，在 ROI 指標中排除。
2. 工具：LabelMe（多邊形）→ 輸出 PNG 遮罩（0/255）。
3. 每張一人標、另一人檢查；有爭議的在週會上決定。
4. 存放位置：`datasets/roi_masks/kodimXX.png`，並在 MANIFEST 記錄標註者和日期。

## 4. 實驗 E1：消融實驗

### 4.1 組別

| 組別 | 語意 | 邊緣 | 抖色 | 設定覆寫值 | 目的 |
|---|---|---|---|---|---|
| **A** 基準組 | ✕ | ✕ | 關 | `alpha=0, beta=0, dither=false` | 標準 K-Means |
| **B** 只有邊緣 | ✕ | ✓ | 關 | `alpha=0, beta=β*, dither=false` | 幾何的貢獻 |
| **C** 只有語意 | ✓ | ✕ | 關 | `alpha=α*, beta=0, dither=false` | AI 的貢獻 |
| **D** 完整方法 | ✓ | ✓ | 關 | `alpha=α*, beta=β*, dither=false` | 融合的貢獻 |
| **E** 完整方法 + 抖色 | ✓ | ✓ | 開 | `alpha=α*, beta=β*, dither=true, gamma=γ*` | 渲染的貢獻 |

α\*、β\*、γ\* 由 E3、E4 在驗證集上決定後鎖定。B 組的 β 和 C 組的 α 要不要各自調到最佳？見 `DISCUSSION.md` 第 7 題（建議：各自在驗證集上調到最佳，比較才公平）。

### 4.2 固定條件

- 同一份資料、同一個 K、同一組亂數種子、同一種初始化方式（加權 k-means++，A 組權重全為 1）、同一支評估腳本、同一台硬體。
- **多個亂數種子**：每個（影像、組別、K）組合都跑種子 {0,1,2,3,4}，報告平均 ± 標準差，排除初始化運氣的影響。

### 4.3 設定檔範例

```yaml
name: ablation_main
split: test
seeds: [0, 1, 2, 3, 4]
K_list: [8, 16, 32, 64]
base:
  n_fit: 200000
  max_iter: 50
  tol: 1.0e-4
  edge_mode: gray
groups:
  A: {use_semantic: false, use_edge: false, alpha: 0.0, beta: 0.0, dither: false}
  B: {use_semantic: false, use_edge: true,  alpha: 0.0, beta: 1.0, dither: false}   # β 由 E3 決定
  C: {use_semantic: true,  use_edge: false, alpha: 1.5, beta: 0.0, dither: false}   # α 由 E3 決定
  D: {use_semantic: true,  use_edge: true,  alpha: 1.5, beta: 0.5, dither: false}   # 由 E3 決定
  E: {use_semantic: true,  use_edge: true,  alpha: 1.5, beta: 0.5, dither: true, dither_gamma: 0.5}
```

（數值只是範例，正式數值由 E3 決定。）

### 4.4 規模估算

測試集約 60 張 × 5 組 × 4 個 K × 5 個種子 = 6,000 次執行。每次約 2～5 秒（S 已快取），合計約 3～8 小時 CPU。可以分批過夜跑，或三人電腦各跑一部分影像，最後合併 CSV。

## 5. 實驗 E2：K 掃描／率失真

- K ∈ {8, 16, 32, 64, 128, 256}；A、D 兩組必跑，B、C、E 視時間而定。
- 橫軸：實際 bpp；縱軸：ROI-PSNR、全圖 PSNR、SSIM、ΔE2000（各畫一張）。
- **重要提醒：** v1 是固定位元打包，同一個 K 下各方法的 bpp 相同，曲線只會在縱軸方向分開；圖說要寫清楚。如果完成 X1 熵編碼，再加畫一組「熵編碼後 bpp」的率失真圖，這時抖色和權重都會影響 bpp。
- 可以加參考線：相同 K 下 PNG-8 / GIF 的檔案大小（X5）。

## 6. 實驗 E3：α/β 敏感度分析

### 6.1 流程

```text
grid_alpha = [0, 0.5, 1.0, 1.5, 2.0]      # 若最佳點在邊界，再往外擴到 [0, 4]
grid_beta  = [0, 0.5, 1.0, 1.5, 2.0]
for (α, β) in grid_alpha × grid_beta:
    for image in 驗證集:
        for seed in [0,1,2]:
            跑 K = 16（主要）和 K = 8（檢查用）
            記錄 ROI-PSNR、全圖 PSNR、邊緣 F1、執行時間
score(α,β) = 對所有影像平均( ΔROI-PSNR − λ · max(0, −Δ全圖PSNR − τ) )
             # Δ = 相對於同一張圖、同一個種子的基準組（α=β=0）
             # τ：可以容忍的全圖 PSNR 下降（例如 0.5 dB）；λ：懲罰權重 → 由 DISCUSSION 第 8 題決定
選出 (α*, β*) = 讓 score 最大的組合；然後鎖定
```

### 6.2 產出

- α×β 熱圖（ROI-PSNR、全圖 PSNR、綜合分數各一張），對應簡報第 11 頁。
- 如果最佳點落在網格邊界，就擴大網格再跑。
- 檢查穩定性：K=8 和 K=16 的最佳區域是否接近？如果不接近，就在報告中說明「α/β 和 K 有交互作用」。

### 6.3 延伸 X3

用影像特徵（例如 S 的平均值、前景面積比例、邊緣密度）預測 α/β 的小模型（線性迴歸或小型多層感知器）。v1 完成後才做。

## 7. 實驗 E4：抖色與 γ

- 固定 α\*、β\*，K ∈ {8,16}；γ ∈ {0, 0.25, 0.5, 0.75, 1.0}；蛇形掃描開／關。
- 觀察重點：全圖 PSNR 通常會**下降**（抖色會增加逐像素誤差），但色帶會減少，ΔE 在區域平均的意義下可能改善。要報告這個取捨，並附局部放大圖。
- 選用指標：先做高斯模糊（模擬人眼的低通特性）再算 PSNR/ΔE，量化「遠看」的品質。

## 8. 實驗 E5：工程指標

| 指標 | 量法 |
|---|---|
| 編碼時間（分段） | 分割／邊緣／融合／VQ／抖色／打包各自計時，取 3 次的中位數，排除第一次載入模型和 Numba 編譯 |
| 解碼時間 | 解包 + 查色票 |
| 記憶體峰值 | `tracemalloc`（Python 物件）或 `psutil`（行程常駐記憶體） |
| 檔案大小／bpp | 實際寫出檔案的位元組數 |
| 硬體 | 報告中寫明 CPU 型號、記憶體、作業系統、Python 和套件版本 |

## 9. 統計與呈現

- 每個（組別、K）報告平均 ± 標準差（跨影像與種子）。
- **成對比較**：在同一張影像、同一個種子下計算 D − A 的差值，用 **Wilcoxon 符號秩檢定**（適用於非常態的成對資料）判斷是否顯著；同時報告 p 值和「改善的影像比例」（勝率）。
  - 關鍵字：`scipy.stats.wilcoxon` — <https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.wilcoxon.html>（需要時再加入依賴）
- **分組呈現**：有 VOC 物件對沒有 VOC 物件；合成影像對自然影像。
- **定性比較圖**：每組挑 3 張（最好、中位數、最差）並排 + 局部放大 + W 熱圖。
- **不要事先宣稱**「全面優於基準組」；結果出來再寫結論。
